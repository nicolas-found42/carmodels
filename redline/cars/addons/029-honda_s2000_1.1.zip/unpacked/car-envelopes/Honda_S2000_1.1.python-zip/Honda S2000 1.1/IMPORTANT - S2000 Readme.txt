NOTICE: In order for this plugin to work properly, you must remove the old version of the plugin from the Plugins folder first. The model files have the same name, and Redline loads the old model by default. If you don't see a rear wing on the S2000, you need to remove the original version of the plugin from the Plugins folder! Don't say I did not warn you!

Power: 179 Watts at 8300 RPMTorque: 207 Newtons/meter at 7500 RPMRedline: 9000 RPM, 9400 for RedlineGear Ratios:From the Honda S2000 Shop Manual at www.hondahookup.com1st = 3.133 -> 45.85 Mph2nd = 2.045 -> 70.35 Mph3rd = 1.481 -> 101.57 Mph4th = 1.161 -> 133.78 Mph5th = 0.971 -> 174.64 Mph6th = 0.811Rev = 2.800Final Drive: 4.1

Lift is measured here as a percentage of total car weight
