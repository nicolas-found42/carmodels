Task from the user: move the Midnight Club: Los Angeles .7z from ~/Downloads into a new midnight-club-los-angeles folder in this repo, set that folder up like the other game folders (game-files/ for the never-committed original input, cars/ for the extraction, a README, reproducible extraction tool with --check, tests, .gitignore entries, research note, check registration), then extract the car models from the game into its ./cars folder.
Repo conventions: native extraction only (like gran-turismo-4), a verifier re-derives every output from the pinned input and rejects missing/extra/changed/linked output, every tool has a test that runs in tools/check.sh, notes state what is not established, large re-derivable native data stays local with index/provenance committed. The disc is an Xbox 360 XGD2 image whose RPF3 archive table is AES-encrypted; the key must not be committed.
Established design (from inspecting the disc; each step is required to reach the car files): the disc is XDVDFS; car files are inside xarchive_cache.rpf, an RPF3 archive whose table is AES-256 encrypted; the key is embedded in the game executable default.xex, which is itself AES-128 encrypted with basic (uncompressed) packing, so tools/xex2.py decrypts default.xex to locate the key by SHA-256 pin; tools/aes_decrypt.py provides AES because stock python3 has no crypto module; tools/xdvdfs.py lists the disc; tools/mcla_rpf.py reads the archive; tools/extract_mcla_cars.py selects car files and verifies them.
Follow-up from review: extract_mcla_cars.derive was split into open_archives, name_sources (streamed), vehicle_codes and emit_cars without changing any output byte (the real-disc --check still matches); an unreachable fallback and an unreachable destination check were removed; every rejection branch of the readers now has a control, and tools/line_coverage.py (check line_coverage) measures 100% executed lines for the five new modules. run_checks.py also registers line_coverage, and CONTRIBUTING.md lists it.
This review covers tools/aes_decrypt.py, tools/xdvdfs.py, tools/xex2.py, tools/mcla_rpf.py and their tests.
