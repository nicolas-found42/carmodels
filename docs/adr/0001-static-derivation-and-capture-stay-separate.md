# Receipts keep static derivation and capture evidence separate

Render fidelity cannot be settled by reading code alone, and a capture alone does not say which code produced it. Receipts therefore record which kind of evidence each claim rests on, carry `claim_limits`, and keep `render_fidelity_complete: false` until a check that can fail on a capture closes the claim; a static derivation is never worded as execution evidence. The cost is hedged notes and conditional wording where a stronger claim would read better, accepted because committed receipts are cited by later work and are hard to retract.
