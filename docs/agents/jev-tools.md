# Jev tool arguments

Generated by `python3 tools/jev_mcp_call.py --schema-doc`; regenerate it when the server changes. Unknown arguments are
rejected, so use these names exactly. The `jev` skill says when to use each tool; read its `reference/tools.md` first.

## `jev_audit`

Audit extracted values against the text they claim to come from, before the values are trusted: one request with a per-value failure-mode battery (hallucinated / off-target / incomplete / wrong format.

| Argument | Type | Required | Meaning |
| --- | --- | --- | --- |
| `source` | string | yes | The text the values claim to come from: a document, or the dense transcript a vision or ASR model produced. Truncated at 50,000 chars. |
| `records` | array[] | yes | Extracted values to audit against the source. Up to 32 per call. |
| `wrong_at` | number |  | A record's P(wrong) at or above this flags the value and escalates. Default 0.7. |

| Argument | Type | Required | Meaning |

| `purpose` | string |  | What this classification is for; shared across all items. |
| `context` | object | string |  | Shared context available to every item's judgment: policies, catalogs, anything stable. |
| `auto_accept` | number |  | Minimum top probability for auto. Default 0.85. |
